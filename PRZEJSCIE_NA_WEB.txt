KROK 2 — WŁĄCZ INFORMACJĘ (wiersze web= i wygaszenie=)
───────────────────────────────────────────────────────────────────────
  2a. Na komputerze, w folderze z programem, w oknie poleceń:
        python przygotuj_przejscie.py  https://adres-aplikacji/  RRRR-MM-DD
      (adres = stały adres aplikacji web, data = pierwszy dzień BEZ
      programu). Skrypt sprawdza adres (tylko https) i daty, a potem
      zapisuje plik PRZEJSCIE_gotowe.txt z czterema częściami:
        1) wiersze do wersja.txt,
        2) wiadomość do zespołu,
        3) instrukcja i pytania,
        4) przypomnienie i tekst na dzień wyłączenia.
      Błąd (np. adres z http:// albo wyłączenie za blisko blokady) →
      komunikat mówi, co poprawić. Niczego nie wysyła.
      Własna data blokady:  --blokada RRRR-MM-DD  (domyślnie dziś + 14).
  2b. GitHub → Code → gałąź main → wersja.txt → ołówek „Edit this file".
      Pierwszych DWÓCH linii (numer wersji i opis) NIE ruszaj. Wszystko
      od trzeciej linii zamień na cztery wiersze z części 1):
          min=3.25.1
          blokada=RRRR-MM-DD
          web=https://adres-aplikacji/
          wygaszenie=RRRR-MM-DD
      „Commit changes…" → „Commit directly to the main branch" →
      „Commit changes". Dalej niczego w tym pliku ręcznie nie zmieniasz;
      robot po każdym wydaniu zachowuje te cztery linie.
  2c. SPRAWDŹ (po 1–5 minutach):
        https://raw.githubusercontent.com/anowicki0205-coder/pmt-planer/main/wersja.txt
      Ma być sześć linii: numer, opis, min=, blokada=, web=, wygaszenie=.
      Adres w web= zaczyna się od https:// i nie ma spacji. Z
      http:// albo ze spacją program go odrzuci i okno się nie pokaże.

  Co się stanie od tej chwili:
  · program 3.25.1 przy najbliższym starcie z internetem pobiera
    wersja.txt i zaczyna pokazywać okno informacji (raz dziennie),
  · program 3.24.0 i starszy pokazuje okno aktualizacji; po dacie
    blokada= nie uruchomi się bez aktualizacji,
  · w dniu wygaszenie= program 3.25.1 pokazuje okno i się zamyka.
  BEZ linii web= program niczego nie pokazuje — to jest wyłącznik.
  Samo wygaszenie= bez web= nic nie robi.

HAMULEC AWARYJNY
───────────────────────────────────────────────────────────────────────
  Przesunięcie terminu: edytuj w wersja.txt jedną linię wygaszenie=
  (nowa data, format RRRR-MM-DD). Zadziała u każdego przy najbliższym
  uruchomieniu z internetem. Nowa data ma być co najmniej 7 dni po
  blokadzie.
  Odwołanie okna: usuń linie web= i wygaszenie= z wersja.txt. Program
  przestaje pokazywać informację po następnym kontakcie z internetem
  (pobrany plik jest jedynym źródłem prawdy). Gdyby sieć odpowiedziała
  zbyt wolno, program po terminie może jeszcze raz się zamknąć —
  wtedy wystarczy uruchomić go ponownie.
  Aplikacja web nie działa albo adres jest zły: NATYCHMIAST usuń linie
  web= i wygaszenie=, napraw adres w skrypcie (KROK 2) i dopisz je
  jeszcze raz. Adres wpisany w web= trafia do ludzi w oknie — zły adres
  to pomyłka widoczna dla wszystkich.


GDY COŚ NIE GRA
───────────────────────────────────────────────────────────────────────
  Okno informacji się nie pojawia
      → otwórz wersja.txt (raw, adres w KROKU 2c): czy jest linia web=
        i czy zaczyna się od https:// i nie ma spacji?
      → czy program ma wersję 3.25.1? Starsze pokażą okno aktualizacji,
        nie okno informacji (zakładka „O programie").
      → czy komputer ma internet? Okno pojawia się po pierwszym
        pobraniu wersja.txt; potem działa także bez internetu.
      → okno raz dziennie: na drugi start tego samego dnia go nie ma.
  Skrypt przygotuj_przejscie.py zgłasza błąd
      → komunikat podaje powód. Najczęściej: adres bez https://,
        data w złym formacie (ma być RRRR-MM-DD) albo wyłączenie za
        blisko blokady.
  Okno ma adres, który się nie otwiera
      → patrz HAMULEC AWARYJNY.
  Ktoś pisze, że „program nie chce się uruchomić"
      → po dacie wygaszenia to zamierzone. Wyślij mu adres aplikacji
        i ten sam kod/hasło.
  Ktoś nie pamięta hasła
      → „Nie pamiętam hasła" na ekranie logowania aplikacji (reset
        numerem telefonu z arkusza).
